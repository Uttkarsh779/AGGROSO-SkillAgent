# Support Guidelines

## Overview
These guidelines define how support agents (human or AI) should handle customer inquiries and create support tickets.

## Support Ticket Priorities

### High Priority
Tickets that require immediate attention and must be resolved within 4 hours:
- Payment processed but order not created
- Account locked or inaccessible
- Data loss or corruption
- Security breach or unauthorized access
- Complete service outage affecting the customer

### Medium Priority
Tickets to be resolved within 24 hours:
- Order delivered incorrectly or incomplete
- Refund not received within expected timeframe
- Billing discrepancy on invoice
- Feature not working as documented
- Subscription renewal issues

### Low Priority
Tickets to be resolved within 72 hours:
- General product questions
- Feature requests
- Minor UI issues
- Account preference changes
- Documentation requests

## Ticket Creation Guidelines

### Required Fields
Every support ticket must include:
- Customer ID
- Issue description (clear, specific)
- Priority level (based on guidelines above)
- Any transaction IDs or order IDs referenced

### Ticket Title Format
Good ticket titles are specific and actionable:
- Good: "Payment deducted for Order #ORD-2045 but order not created"
- Good: "Customer C102 - Billing dispute for Jan 2024 charge"
- Bad: "Customer has a problem"
- Bad: "Billing issue"

## Handling Payment/Billing Issues
Payment and billing issues are the most sensitive category:
1. Always acknowledge the customer's concern immediately
2. Retrieve the customer record before making any claims
3. Check billing system before confirming any charge
4. Do not promise refunds without verifying eligibility
5. Create a HIGH priority ticket if payment was deducted without order creation
6. Escalate to billing team if you cannot resolve within 2 hours

## Customer Communication Standards
- Always address customer by name when available
- Acknowledge the issue clearly in the first response
- Provide estimated resolution time
- Do not leave tickets unattended for more than 2 hours during business hours
- Always close the loop — confirm resolution with customer before closing ticket
